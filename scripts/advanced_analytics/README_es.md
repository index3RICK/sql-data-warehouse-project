# 📊 Análisis Avanzado

Transformación de datos de negocio en información accionable utilizando técnicas analíticas de SQL sobre la **capa Gold** del Data Warehouse.

---

## 📌 Descripción

Este módulo contiene una colección de consultas SQL diseñadas para responder preguntas frecuentes del negocio. Los análisis realizados sirven como base para dashboards, reportes ejecutivos y la toma de decisiones.

---

## 📈 Módulos Analíticos

### ⏳ 1. Análisis de Tendencias

Analiza la evolución del negocio a lo largo del tiempo.

- Ventas Mensuales
- Clientes Mensuales
- Cantidad Vendida

---

### 📈 2. Análisis Acumulativo

Calcula el crecimiento progresivo del negocio.

- Ventas Acumuladas
- Rendimiento Acumulado

---

### 🚀 3. Análisis de Desempeño

Evalúa el rendimiento de los productos.

- Comparación Año contra Año
- Comparación con el Promedio Histórico
- Clasificación del Desempeño

---

### 🥧 4. Análisis Parte-Todo

Determina cuánto aporta cada categoría al total del negocio.

- Ventas por Categoría
- Participación Porcentual

---

### 🎯 5. Segmentación de Datos

Clasifica entidades del negocio utilizando reglas comerciales.

#### Segmentación de Productos

- Menor a 100
- 100 – 500
- 500 – 1000
- Mayor a 1000

#### Segmentación de Clientes

- 🟢 VIP
- 🔵 Regular
- 🟡 Nuevo

---

## 🛠 Tecnologías

- PostgreSQL
- SQL
- Funciones de Ventana
- CTE (Common Table Expressions)
- Vistas
- Analítica de Negocio

---

## 🎯 Objetivo

Demostrar técnicas de SQL ampliamente utilizadas en proyectos de **Ingeniería de Datos**, **Business Intelligence** y **Analítica de Datos** para generar información de valor a partir de datos consolidados.
